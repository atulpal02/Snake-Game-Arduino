# Retro Snake Game on Arduino 🎮

## Overview

The **Retro Snake Game** is an academic project developed as part of the **Electronic Design Workshop (2023–24)** at the **ECE Department, Netaji Subhas University of Technology (NSUT)** under the guidance of **Mr. D. V. Gadre**.

The project implements the classic Snake game on an **Arduino Uno**, combining **C/C++ programming with hardware interfacing**. The system uses push buttons for user input, an LCD display for game visualization, and a buzzer for audio feedback.

## Hardware Components

* Arduino Uno
* Alphanumeric I2C LCD Display
* Push Buttons
* Buzzer
* Resistors
* Breadboard and connecting wires

## Features

* Real-time Snake movement and controls
* LCD-based game visualization
* Push-button input handling
* Food generation and snake growth
* Wall and self-collision detection
* Dynamic game speed
* Buzzer-based audio feedback
* Button debouncing for reliable input handling
* Menu, Play, Win, and Game Over states

## What I Learned

This project was an **enriching hands-on learning experience** that helped me move beyond writing software purely on a computer and understand how software interacts with physical hardware.

Through this project, I gained practical experience in:

* Programming an embedded system using **C/C++ and Arduino**
* Interfacing software with physical hardware components such as **buttons, LCD displays, and buzzers**
* Working with **GPIO inputs and outputs** and **I2C communication**
* Implementing real-time game logic, including movement, collision detection, state management, and timing
* Handling physical button inputs and implementing **debouncing** for reliable operation
* Designing, prototyping, integrating, and testing a complete hardware-software system

## Experience

One of the most valuable aspects of this project was seeing how **software and hardware come together to create a working system**. Writing the game logic in C/C++ was only one part of the project; integrating it with physical components, testing the circuit, debugging hardware behavior, and ensuring that the software responded correctly to real-world inputs made the experience especially valuable.

This project gave me my first significant hands-on exposure to **embedded systems and hardware-software integration**, and strengthened my interest in understanding how algorithms and software can be implemented on physical computing platforms.
